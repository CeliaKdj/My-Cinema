# My cinéma :
Application web de gestion pour un cinéma

## Structure et informations principales du projet :
* Front-end : HTML, CSS, Javascript, et Tailwind (choix personnel)
* Back-end : PHP, MySQL
* Base de données : PDO
* Séparation du back-end et front-end en créaant un dossier pour chaqu'une des ces parties
* Le projet suit une architecture MVC (Modèle-Vue-Contrôleur) pour séparer la logique métier de l'interface utilisateur

### Installation :
* Clonage du projet sur le repository Epitech avec les commandes suivantes : 
    - git clone git@github.com:EpitechWebAcademiePromo2027/W-WEB-102-LIL-1-1-my_cinema-6.git
* Verification version PHP : ici nous avons besoin de PHP 8.3 minimum (sans framework)
* Installation de l'environnement LAMP contenant MySQL, Apache et PHP pour le systême d'exploitation Linus
* Création des dossiers et fichiers dans deux dossiers distincts :
    - frontend : contient "le code HTML, CSS, JavaScript de votre projet, ainsi que les ressources nécessaires (images, polices éventuelles, etc)."
    - backend : contient "exclusivement le code PHP et MySQL du projet."
